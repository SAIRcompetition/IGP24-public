# IGP24 Baseline

`baseline_pairs.csv` is the draft public baseline of known `(24Tn, r)` pairs for
IGP24 scoring.

Columns:

```text
label,r
```

The current draft baseline is regenerated by
`public package/tools/build_reference_examples.py` from:

```text
frozen LMFDB degree 24 snapshot
plus public reference examples in ../../public package/materials/
```

Current draft coverage is summarized in
`../../public package/README.md` and
`../../public package/materials/summary.json`.

Before public launch, freeze this file in git.
