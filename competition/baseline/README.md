# IGP24 Baseline

This directory holds two reference tables for IGP24 scoring. Both use the
columns `label,r`.

## `valid_pairs.csv`

The complete universe of group-theoretically possible degree-24 signatures
`(24Tt, r)` -- 165,836 rows. For every transitive group `G` of degree 24
(labels `24T1` through `24T25000`), `r` is the number of real roots of the
polynomial, i.e. the number of fixed points of complex conjugation. Complex
conjugation is an element of `G` of order dividing 2, so the possible values of
`r` for `G` are the fixed-point counts of the involutions of `G`, together with
`r = 24` (the identity, a totally real field).

No submitted polynomial can ever realize a `(24Tt, r)` pair outside this file;
it is the full target space for the competition. Regenerated by
`public package/tools/gen_valid_pairs.m` (Magma, using the transitive groups
database).

## `lmfdb_baseline.csv`

The draft public baseline polynomials that are already included in the LMFDB,
together with their Galois group, signature, and polynomial discriminant. A valid
polynomial equivalent to one of these will be accepted but will score no points,
and submissions for these Galois groups will need to beat these discriminants
in order to count.
Generated by `public package/tools/gen_lmfdb_baseline.py` from the
LMFDB degree 24 data.

Before public launch, freeze both files in git.
